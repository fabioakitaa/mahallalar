# Mahallalar

O'zbekiston mahallalari geo-poligon ma'lumotlari (Deyarli hammasi) 

Comprehensive dataset of geographical polygons and coordinates for local neighborhood communities (Mahallas) in Uzbekistan.

### UZ

Ushbu repozitoriy O'zbekistondagi mahallalarning (deyarli barchasining) geo-poligon va lokatsiya ma'lumotlarini o'z ichiga olgan ochiq ma'lumotlar to'plamidir (dataset). Loyiha xaritalar, GIS tizimlari hamda tahliliy loyihalarda foydalanish uchun mo'ljallangan.

### 📂 Fayllar Strukturasi

Ma'lumotlar viloyat va tuman ID lari bo'yicha tartiblangan:

mahallas/
└── {region_id}/
    ├── {district_id_1}.json
    ├── {district_id_2}.json

### EN

This repository is an open-source dataset containing geographical boundaries, location, and polygon data for local neighborhood communities (Mahallas) across Uzbekistan (nearly all covered). Designed for GIS mapping, spatial analysis, urban planning, and location-based application development.

### 📂 File Structure

The dataset is organized by region and district administrative IDs:

mahallas/
└── {region_id}/
    ├── {district_id_1}.json
    └── {district_id_2}.json
